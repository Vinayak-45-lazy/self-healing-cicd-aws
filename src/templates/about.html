About This Project

This is a complete end-to-end self-healing deployment setup on AWS. It is built as a placement preparation project to demonstrate advanced DevOps principles.

How It Works:

  • Continuous Integration: Code push triggers CodePipeline. CodeBuild runs pytest tests and packages the app.
  • Continuous Deployment: CodeDeploy performs an in-place deployment on our Ubuntu EC2 instance.
  • Health Verification: CodeDeploy runs post-install bash scripts to verify the /health endpoint.
  • Automated Self-Healing: In case of standard instance health failures, AWS CloudWatch alarms trigger a Python AWS Lambda function. The function retrieves the last stable deployment and invokes a CodeDeploy rollback programmatically.
